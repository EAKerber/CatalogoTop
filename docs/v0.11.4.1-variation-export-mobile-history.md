# v0.11.4.1 — Variation Export & Mobile History Hotfix

Hotfix de estabilização da V1, sem ampliar o escopo da futura V2.

## Exportação de imagens externas

O catálogo pode renderizar uma imagem absoluta `http(s)` mesmo quando o JavaScript do navegador não consegue obter seus bytes por `fetch()` devido a CORS. A partir deste hotfix, o Image Variation Request tenta primeiro embutir a imagem como antes. Se essa tentativa falhar **e somente se a fonte canônica `product.image` for uma URL absoluta HTTP(S)**, o job continua elegível com `source.mode = "remote-url"` e a URL canônica no manifest.

O Request Bundle v2 distingue:

- `source.mode = "embedded"`: bytes, SHA-256 e `source.path` estão dentro do ZIP;
- `source.mode = "remote-url"`: o ZIP contém apenas o locator externo e um fingerprint SHA-256 do locator. O agente externo é responsável por recuperar essa URL segundo sua própria política de rede/segurança.

Assets gerenciados relativos (`/api/assets/...`) continuam fail-closed se ficarem indisponíveis. O editor não ganhou proxy genérico de URL externa e, portanto, não abriu uma superfície SSRF no backend.

## Histórico mobile

Desfazer/refazer continua pertencendo somente à aba **Catálogo**. Em viewport mobile os controles são movidos para o header global apenas enquanto Catálogo está efetivamente ativo. Ao entrar em Produtos ou Templates eles são fisicamente devolvidos ao `heading-actions` do painel Catálogo e permanecem `hidden`, evitando vazamento de chrome global mesmo se regras responsivas futuras mudarem.

O Browser Gate verifica fora de Catálogo:

- `hidden === true`;
- `display: none`;
- bounding box `0 × 0`;
- parent fora de `.app-primary-tools`.

Ao retornar para Catálogo, o gate exige que os controles voltem ao header mobile e que o snapshot de undo/redo seja preservado.

## Não alterado

- `product.image` permanece o Original canônico;
- Result Bundle e importação transacional permanecem inalterados;
- nenhuma URL externa é promovida ou copiada para ProductStore por efeito colateral;
- nenhuma Function Netlify nova foi adicionada;
- pipeline A4, `CatalogDocument`, framing e preview/print permanecem inalterados.
